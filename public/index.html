Where do I find my character file?

Windows (Steam)%AppData%\LocalLow\IronGate\Valheim\characters_local\
macOS (native Steam/App Store build)~/Library/Application Support/IronGate/Valheim/characters_local/
Linux (native)~/.config/unity3d/IronGate/Valheim/characters_local/
Steam Deck / Linux (Proton)~/.local/share/Steam/steamapps/compatdata/892970/pfx/drive_c/users/steamuser/AppData/LocalLow/IronGate/Valheim/characters_local/

Older saves may use a folder named characters instead of characters_local — check both if one doesn't exist. If you're running Valheim on Mac through Whisky/CrossOver instead of the native build, look inside that compatibility layer's emulated AppData folder using the Windows path above.

Valheim's .fch/.fwl save format isn't officially documented, and the 1.0 release changed it enough that even community references are out of date. This viewer wouldn't exist without:

  • Kakoen/valheim-save-tools — a Java library whose ZPackage/WorldPlayerData/PlayerData source was the primary reference for the binary layout this tool implements.
  • cquaid/valheim-fch-editor — an earlier field-by-field format write-up that provided the starting map before it was cross-checked against a real, newer save file.
  • Cytoscape.js — powers the per-world pin map.
  • A decompiled PlayerProfile.cs, contributed by a project maintainer from their own legally-owned Valheim install — real ground truth that resolved most of the guesswork above (see README.md).

See README.md in this project for how the format gaps were actually tracked down, and REVERSE_ENGINEERING_FROM_SOURCE.md for what it'd take to confirm the rest against Valheim's own C# source.
